# Flash-Card Viewer (Web版)

Pythonista 3 用の暗記カードアプリ (`pythonista/test.py`) を、**ブラウザだけで動く 1 枚の HTML** に移植したもの。

- Pythonista (iPhone 限定・買い切り 1,500 円) が要らない
- iPhone / Android / PC のブラウザならどこでも同じ画面
- ホーム画面に追加すればアプリと同じ全画面表示、**オフラインでも動く**
- 問題はアプリ内で追加・編集できる (Pythonista 版の `list*.json` とも相互に読み書き可能)
- めくるだけでなく、**穴埋め入力・記述式で答えて自動採点**もできる

見た目・操作は Pythonista 版そのままです。ラベルの位置 (14% / 44% / 75%)、
フォント自動縮小、`✔︎ ✘ ↩︎` の 3 ボタン、`☰` メニュー、`✕`、タップで裏返し、
「番号だけ左端揃え・全体は中央寄せ」の答え表示まで再現しています。

## iPhone で使う

### GitHub Pages で公開する (おすすめ)

1. リポジトリの **Settings → Pages** を開く
2. **Source** を `Deploy from a branch` にする
3. **Branch** で `claude/pythonista-app-port-iiou2m` (このリポジトリのデフォルトブランチ)
   を選び、フォルダは `/ (root)` にして Save
4. 1〜2 分後に `https://proxxxxxy.github.io/learnbypy/` が使えるようになる
5. iPhone の Safari でそのURLを開き、共有ボタン → **ホーム画面に追加**

> 無料プランの場合、GitHub Pages は **public リポジトリでしか公開できません**。
> private のままだと Pages の設定画面で有料プランへの案内が出ます。
> public にしたくない場合は下の「ファイルを直接開く」を使ってください。

ホーム画面から起動するとアドレスバーが消えて全画面になり、
一度開いたあとは**機内モードでも動きます**。

### ファイルを直接開く

`index.html` を iPhone にダウンロードして Files アプリから開いてもOK。
ただしこの方法だと問題の保存 (localStorage) がブラウザに残らない場合があるので、
継続して使うなら Pages 経由をおすすめします。

## 操作

| 操作 | 動き |
|---|---|
| 画面をタップ | 表 ⇄ 裏 |
| ✔︎ | 正解にして次へ |
| ✘ | 不正解にして次へ (あとで「不正解だけ」で復習できる) |
| ↩︎ | 1 問戻る (成績も戻る) |
| ☰ | メニュー |
| ✕ | 最初のリスト選択に戻る |

PC ではキーボードも使えます — `Space`/`Enter` でめくる、`→` 正解、`↓` 不正解、`←` 戻る。

### メニュー

- **順番で最初から** / **シャッフルで最初から**
- **表示方向を切替** — 表に答えを出して問題を当てる逆モード
- **リストを選ぶ** — 起動時と同じファイル選択に戻る
- **めくるだけにする / 入力して答える** — 入力式カードの一時切替
- **問題を編集** — 下記のエディタ
- **ファイルの操作** — JSON の書き出し / 読み込み、端末内リストの作成、編集の取り消し

## 問題リストは `lists/` の JSON ファイル

Pythonista 版が `list*.json` を探して選ばせていたのと同じで、
このアプリも **`lists/` に置いた JSON ファイルから選んで始めます**。
静的サイトはフォルダの中身を一覧できないので、
**`lists/index.json` に並べたものが選択肢になります**。

```
lists/
  index.json           ← 選択肢の一覧 (これに書いたものが出る)
  semiconductor.json   ← 実際の問題
```

```json
// lists/index.json
[
  { "file": "semiconductor.json", "name": "半導体" },
  { "file": "eiwa.json",          "name": "英単語" }
]
```

`"name"` が選択画面に出る表示名です。ファイル名だけの文字列で書いてもOK
(`["semiconductor.json"]` → 表示名は `semiconductor`)。

問題ファイルの中身は Pythonista 版と同じ `[番号, 問題文, 答え]` の配列です。

```json
[
  [1, "pn接合の(1)障壁により整流作用を発現する。", "(1)電位"],
  [2, "次の用語を答えよ。", "(1)あああ\n(2)いいい"]
]
```

- **番号** — 表面に `番号. 問題文` として出ます。数字でなくても構いません (`A2` など)
- **答え** — 改行 (`\n`) で区切ると `(1)(2)…` の行が左端で揃って縦に並びます

## 出題形式 (めくるだけ以外)

4 番目の要素に**形式**を書くと、答えを**入力して自動採点**させられます。
書かなければ従来どおり「めくって答えを見るだけ」です。

| 形式 | 動き |
|---|---|
| (なし) | めくるだけ。Pythonista 版と同じ |
| `"fill"` | **穴埋め入力**。問題文の `(1)(2)…` に対応する入力欄が並ぶ |
| `"write"` | **記述式(自動採点)**。用語など短い答え向け。○× が付く |
| `"self"` | **記述式(自己採点)**。長い説明向け。模範解答だけ出るので自分で ✔/✘ |

```json
[
  [1, "システムの(1)とは、許容できない(2)がないことをいう。",
      "(1)安全|セーフティ\n(2)リスク", "fill"],

  [2, "故障時に安全側に向かう設計思想を何というか。",
      "フェールセーフ", "write"],

  [3, "リスクアセスメントの手順を説明せよ。",
      "危険源の同定 → リスク見積り → リスク評価 → 低減措置", "self"],

  {"no": 4, "q": "オブジェクト形式でも書けます", "a": "こたえ", "type": "write"}
]
```

- **穴埋め (`fill`)** は答え側の `(1)(2)…` を入力欄に割り当てます。
  `"(1)ワード\n(2)ビット"` でも `"(1)PNP, (2)アノード"` でもどちらの書き方でも拾います
- **別解**は `|` で区切ります。`"ホール|正孔"` ならどちらでも正解。
  カードに表示されるのは最初のものだけです
- 採点は**全角/半角・大文字小文字・空白・句読点・ひらがな/カタカナ**の違いを吸収します
  (`ほーる` と打っても `ホール` に一致)
- 自動採点の結果は ✔ か ✘ に黒枠で提示されますが、**最終判断は自分**です。
  惜しい答えは ✔ を押せばそのまま正解に数えられます
- ☰ → **めくるだけにする** で、入力式のカードも一時的にめくるだけに切り替えられます
  (通学中にざっと流したいとき用)

### 問題を増やす手順

1. `lists/` に `なまえ.json` を追加してコミット
2. `lists/index.json` にその1行を足してコミット
3. push すれば数分で iPhone 側にも出てきます (アプリを開き直す)

一度開いたファイルは端末にキャッシュされるので、**圏外でも選んで解けます**。

### 端末の中だけで作る

外出先で思いついた問題は、アプリの中でも作れます。
☰ → **ファイルの操作 → 新しいリストを作る (端末内)** で空のリストを作り、
**＋ 追加** から 1 問ずつ入力。既存のリストも ☰ → **問題を編集** から
編集・並べ替え・削除できます。

- 編集した内容は**端末の中にだけ**保存され、`lists/` の JSON は書き換わりません
  (メニューに `※編集あり` と出ます)
- **ファイルの操作 → JSON を書き出す** で外に出せるので、
  それをリポジトリの `lists/` に置けば正式版になります
- **編集を捨ててファイルに戻す** でいつでも元の JSON の状態に戻せます

> 端末内のリストと編集内容はブラウザの中にしかありません。Safari の
> 履歴/サイトデータを消すと一緒に消えるので、大事なものは JSON に書き出して
> リポジトリに入れておくのが確実です。

## ファイル構成

```
index.html                 アプリ本体 (これ 1 つで動く)
manifest.json / sw.js      ホーム画面追加とオフライン動作用
lists/index.json           問題リストの一覧
lists/semiconductor.json   「半導体」23問
pythonista/                移植元の Pythonista 版 (参考用)
```

`index.html` の中に `lists/semiconductor.json` と同じ内容が埋め込んであるので、
ファイルがまったく取得できない状況 (`file://` で直接開いた等) でも
「半導体」だけは動きます。

## ローカルで動かす

`index.html` をブラウザにドラッグするだけでも動きますが、
オフライン動作 (Service Worker) まで試すなら簡易サーバー経由で:

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## Pythonista 版との対応

| Pythonista | Web版 |
|---|---|
| `ui.View` / `ui.Label` / `ui.Button` | HTML + CSS (絶対配置で同じ座標) |
| `ui.measure_string` によるフォント縮小 | 実寸を測りながらの二分探索 (`fitFont`) |
| `console.alert` | 同じ見た目のモーダルダイアログ (`alertDialog`) |
| `os.listdir()` で `list*.json` を探す | `lists/index.json` に並べた JSON から選ぶ |
| `touch_ended` | `click` (ボタン上は無視) |
